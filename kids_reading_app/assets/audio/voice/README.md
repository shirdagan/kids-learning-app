# הקלטות קול אמיתיות (במקום TTS)

כל קובץ כאן הוא הקלטה קצרה בפורמט `.m4a`, בשם התואם בדיוק למפתח
שמוגדר בקוד (ראו `lib/services/voice_clip_service.dart`).

- עברית: `assets/audio/voice/he/<שם>.m4a`
- אנגלית (בהמשך): `assets/audio/voice/en/<שם>.m4a`

**אין חובה להקליט הכל בבת אחת.** אם קובץ לא קיים, האפליקציה נופלת
אוטומטית חזרה לדיבור סינתטי (TTS) בלי שום שגיאה — כך שאפשר להוסיף
הקלטות בהדרגה.

הרשימה המלאה של הביטויים למודול הצבעים נמצאת בבריף שנשלח בצ'אט.
